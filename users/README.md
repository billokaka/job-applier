# users/

One folder per person, created by the onboarding interview (prompt 0) from `../templates/`:
`users/<slug>/` with `README.md`, `candidate-profile.md`, `answer-bank.md`,
`onboarding-record.md` and `cv/`.

**Everything in here except this file is git-ignored and private.** It holds a person's facts,
answers and CVs. Never commit it, never copy it into another folder, never paste it anywhere but
in a message to that person. Offboarding (`../ONBOARDING-PLAN.md` §6) exports it to the person and
deletes it here.
